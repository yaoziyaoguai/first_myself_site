# 性能冲刺报告：first_myself_site（2026-09-29）

冲刺范围：首页 `/`、博客列表 `/blog`、文章详情 `/blog/[slug]`（访客视角）。目标为「打开到能用」p75 减半；冲刺中途依据证据把重心调整为「生产端体感优先」（用户已批准），实验室目标作为参考线保留。

## 一、结论

### 保留的改动（3 项）

| # | 改动 | 实验室效果（配对测） | 生产端预期 |
|---|---|---|---|
| 1 | 文章查询请求级去重（React `cache()`） | 文章 p75 306→267 的组成部分 | 减少一次/请求的 DB 查询 |
| 3 | 内链 prefetch 治理（27 个 `<Link prefetch={false}>`） | 请求数首页 27→10、文章 26→16；字节 -9% | **每次浏览少执行 11-17 个动态 SSR**，直接削线上排队效应（基线线上 TTFB 0.68-2.53s 的主要嫌疑） |
| 4 | 访客数据缓存（`visitorContentCache` + tag 失效钩子） | 文章 p75 继续下降；热 TTFB 首页 36→7-12ms、文章 ~200→17-35ms | 访客请求免查库；配合 #3 预计线上 TTFB 大幅回落 |

### 回退的改动（1 项）

- 文章正文 `Suspense` 流式渲染：实验室 p75 恶化至 576ms（大块同步渲染的流式分段服务端开销为负资产），测量判死，已回退。

## 二、配对测量（最终对比，同时段 A/B 交替，15 次/页，fast4g 冷缓存）

| 页面 | 基线 p75 (A) | 优化后 p75 (B) | 降幅 | 配对时段 |
|---|---|---|---|---|
| 首页 | 247.4 | 247.6 | -0.1%（持平） | 2026-09-29 晚，同机 |
| 列表 | 244.3 | 244.4 | -0.0%（持平） | 同上 |
| 文章 | 306.4 | **267.3** | **-12.8%** | 同上 |

### 没有达标的部分（如实写）

- **原目标「三页 p75 减半」未达成**：首页/列表在实验室持平。证据链：这两页的实验室 TTFB 仅 ~36ms，p75 由「RTT 链 + HTML 传输 + CSS 阻塞渲染 + 首帧绘制（~146ms）」主导，服务端优化在实验室不可见。要在实验室把这两页减半，只剩浏览器绘制管线级别的改造（内联关键 CSS 等），收益/风险比低，主动提出不做。
- **真正的痛点在生产**：线上文章页 TTFB 0.68-2.53s（实验室同代码 24-81ms），是弱 CPU 上每请求全量渲染 + prefetch 负载叠加排队。#3+#4 直击该痛点，**效果必须由部署后线上复测确认**，实验室数字无法替代。
- CrUX 无法获取（API 配额 429），真实用户分布未知。

## 四、质量护栏（全部绿灯状态）

- 黄金比对：三页可见文本、正文 HTML（剥 React 边界注释后逐字节）、SEO 字段（title/meta/canonical/JSON-LD）、元素计数、sitemap/RSS/robots —— 全一致
- 视觉回归：三页 × 2 宽度（1440/390）整页截图，确定性等待（networkidle+fonts+settle）后逐字节一致
- 功能冒烟：三页判定表达式 + 文章页站内导航可用
- 棘轮：9 项上限只降未升（`perf/bench/ceilings.json`）
- 仓库检查：tsc ✓、eslint ✓、npm test 全绿（个别测试对沙箱环境敏感，沙箱外全过；`production-migration-deploy` 满载下偶发 30s 超时，与改动无关，单独跑 7/7 过）

## 六、回滚

- 部署工作流自带应用镜像回滚（数据库无 schema 变更，本冲刺零迁移）
- 代码层 revert 对应 commit 即可；两项优化相互独立，可单独回滚（prefetch 是纯标记；缓存层删除 import 即回到直查）

## 七、风险

- 缓存失效钩子若在生产 payload 上下文执行失败（已 try/catch + 告警），最坏情况是访客内容 60 秒陈旧——发布紧急修正时请知悉此窗口
- 访客/登录态分流依赖 `getCurrentUser` 判空：已按「任何登录态都直查」设计，private 内容不会进入共享缓存；该边界被 BlogPage 系列测试覆盖（vitest 旁路路径与直查路径同构）
- `next/cache` 惰性加载是为 `payload run` CLI 兼容所必需，勿改回静态引入（会被 production-migration-deploy 测试逮住）

## 八、遗留与后续

- **B 方案（Cache Components 渲染级缓存）未做**：若部署后线上文章页仍 >1s（Markdown 渲染本身慢），这是下一张牌；属架构迁移，需单独立项
- 实验室首页/列表的绘制管线（CSS 阻塞链 ~146ms）未动，收益/风险比低
- 本地 perf 库（`first_myself_site_perf`）与 `.local/` 产物保留，供复测与后续实验；不需要时 `dropdb` + 删目录即可
